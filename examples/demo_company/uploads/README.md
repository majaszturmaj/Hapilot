# Files to upload in the demo

Not indexed. These are the files the demo script ([docs/demo.md](../../../docs/demo.md)) attaches in the chat
to show work on uploaded files. All content is invented.

| File | Shows |
|---|---|
| `raport_kwartalny_q3_2026.pdf` | summary of a long file (about 22 600 characters, 10 pages: indexed for the session and summarised part by part) |
| `projekt_umowy_sprzatanie.docx` | editing a Word file: typos ("Wykonwaca", "ktróre", "codzienie") and a 14-day payment term to change |
| `regulamin_parkingu.txt` | adding a file to the knowledge base, then answering a question from it |

The binary files are generated by `make_fixtures.py --uploads-only` (the PDF via LibreOffice).
