# Demo company: Przykładowa Sp. z o.o.

Fictional company used for Hapilot's demo knowledge base, smoke tests and examples. Every name,
address and e-mail address here is invented; e-mail addresses use the reserved domain example.com.
Any resemblance to a real company is coincidental.

`docs/` holds documents in every supported format (.txt, .pdf, .docx, .eml, .xlsx); the binary ones are
generated by `make_fixtures.py` (the PDF via LibreOffice). `docs/` is indexed by default (`HAPILOT_DOCS_DIR`). Point `HAPILOT_DOCS_DIR` at your own folder to
use Hapilot with your company's documents — they stay on your machine and are never committed
(`data/private_docs/` is ignored by git).
